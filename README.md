# shopee_app_review
This is my personal project containing data analysis of Shopee app ratings from 2018 to 2024.
I will use the results of this data analysis to conduct business and system analysis.
Disclaimer: This is a personal project created solely for educational and portfolio purposes. The data used is a public dataset obtained from Kaggle (include the Kaggle link if available) and reflects only a specific time period. This dashboard is not affiliated with, sponsored by, or representative of the internal data or official views of Shopee or any related companies.
Link to the Raw Data: https://www.kaggle.com/datasets/ahmadseloabadi/shoppe-app-reviews-from-google-play-store
# Step by step on what i do
1. I extracted data from Kaggle.
2. I performed the first data preparation step, which involved categorizing the comments in the dataset using Python by training a model so that the comments could be divided into 7 categories. (Note: My model training source code can be found in the “Python Source Code” file.)
3. I cleaned the data by removing entries that did not match the existing columns and any empty entries.
4. I performed the second data preparation step, which involved adding positive and negative sentiment based on the score values and categories.
5. I analyzed the data using Looker Studio (now Data Studio).
